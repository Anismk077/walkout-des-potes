# Walkout des Potes

Jeu d'ouverture de boosters dans une ambiance de stade de nuit : trois types de boosters, six raretés (de commune à mythique), compteur de garantie et animation de walkout.

Tout tient dans un seul fichier, `index.html`. Il suffit de l'ouvrir dans un navigateur.

## Mettre en ligne avec GitHub Pages

1. Dans le dépôt, va dans **Settings → Pages**.
2. Dans **Source**, choisis **Deploy from a branch**, puis la branche `main` et le dossier `/ (root)`.
3. Après une minute, le jeu est accessible à `https://<ton-pseudo>.github.io/walkout-des-potes/`, sans compte.
